# BT订阅中心

BT订阅中心是一个面向 BT/RSS 动漫源的 MoviePilot 插件。它把插件内订阅、RSS 候选、识别异常、下载事实、入库状态和整季包替换集中到一个工作台里，适合用来管理只来自指定 BT/RSS 来源的番剧资源。

## 主要功能

- **插件内订阅**：维护独立的番剧订阅列表，不把主链路交给 MoviePilot 原生订阅自动搜索。
- **候选池管理**：从配置的 BT/RSS 来源收集资源，按订阅、季集、识别状态和下载状态归档。
- **动漫/特摄准入**：可信动漫源中识别成真人剧或分类冲突的资源会进入异常闭环，避免直接下错。
- **识别异常处理**：提供异常列表、重扫、智能体处理提示、窄作用域识别词预览与回流入口。
- **下载事实闭环**：记录提交下载后的 hash，持续同步下载器、下载历史、转移历史和媒体库存在状态。
- **入库后清理任务**：确认入库后可清理 qBittorrent 任务，保留源文件。
- **整季包替换**：订阅完结后可监控同组整季包，成功入库后再更新替换状态。
- **Vue 工作台**：提供接近 MoviePilot 订阅体验的订阅卡片、详情页、候选池、异常队列和状态概览。

## 使用建议

1. 在插件配置中填写经过筛选的 BT/RSS 动漫源。
2. 设置保存路径，例如专门的番剧下载目录。
3. 首次使用建议先观察候选池和识别异常，再决定是否开启自动下载。
4. 识别冲突不要急着手动改库，优先通过异常队列生成窄作用域识别词或回流候选。
5. 历史“缺 Hash”记录只用于解释旧版本提交过但不可追踪的下载，不建议直接批量重下。

## 注意事项

- 插件定位是 BT/RSS 番剧订阅中心，不是 MoviePilot 原生订阅的替代品。
- 插件不会主动发送 MoviePilot 通知，状态以页面、插件数据和日志为准。
- 自动下载、清理下载器任务、写入识别词等操作都应保持谨慎，建议先用少量订阅验证。
- 整季包替换需要依赖下载、转移和媒体库事实回写，只有验证成功后才会推进状态。
