# 蓝光原盘重封装

用于处理 MoviePilot 下载或源文件目录里的 ISO、IMG、BDMV 等蓝光原盘资源。插件会先把原盘重封装为 MKV，再交给 MoviePilot 走正常整理入库流程，适合不希望媒体库里留下 Emby/Jellyfin/Plex 难以直接识别原盘结构的场景。

## 主要功能

- 只从配置的“源文件”目录寻找待处理原盘，不把硬链接媒体库当作重封装输入源。
- 支持 ISO、IMG、BDMV 目录结构。
- 电影目录按电影主片逻辑处理；电视剧目录按剧集逻辑拆分，禁止回退成“抽最长主片”的电影模式。
- 重封装完成后通过 MoviePilot 正常整理链路硬链接入库。
- 可规范 MKV 内音轨、字幕轨标题，便于播放器里识别语言、编码和常见轨道特征。
- 提供 Vue 任务控制台，可查看队列、进度、阶段、已用时间、预计剩余时间，并支持暂停、继续、跳过、终止。
- 定时补扫源文件目录，可作为下载整理前拦截之外的兜底。
- 成功入库后可按配置清理源原盘和媒体库旧原盘残留；新生成的 MKV 不会被当成旧原盘删除。

## 处理流程

```text
源文件 ISO/BDMV
  ↓
MakeMKV 重封装为 MKV
  ↓
可选：规范音轨/字幕轨标题
  ↓
MoviePilot 硬链接整理入库
  ↓
可选：清理源原盘、下载器任务、旧媒体库原盘残留
```

## 目录规则

插件依赖源文件目录下的一级类型目录做硬分流：

- `电影` 目录：只按电影主片提取。
- `电视剧` 目录：只按电视剧多集/单集逻辑处理。

电视剧目录下如果无法确认剧集拆分计划，会标记失败或跳过，等待后续补规则或人工处理，不会为了“总能输出一个文件”而错误合并成电影式大包。

## 依赖

- 需要 `makemkvcon`。
- 轨道规范化需要 `mkvmerge` / `mkvpropedit`。
- 时长校验需要 `ffprobe`。

如果容器内缺少 MakeMKV，插件内提供安装脚本，但更推荐在自定义镜像或宿主环境中提前准备好相关工具。

## 常用配置

| 配置项 | 说明 |
| --- | --- |
| 源文件根目录 | 插件只从这些目录寻找 ISO/BDMV 输入源。 |
| 媒体库根目录 | 用于发现旧原盘残留和验证入库结果，不作为重封装输入。 |
| 自动补扫 | 按间隔扫描源文件目录中的漏网原盘。 |
| 并行 worker | 控制最多同时处理几个重封装任务。大盘较多时建议保守。 |
| 磁盘余量门闩 | 低于配置余量时跳过本轮处理，避免重封装把磁盘写满。 |
| 源原盘处理 | 成功入库后保留或删除源文件 ISO/BDMV；删除时会同步清理下载器任务但保留源目录内的 MKV。 |
| 旧媒体库原盘处理 | 新 MKV 入库成功后，保留、忽略或删除媒体库里的旧 ISO/BDMV 残留。 |

## 注意事项

- 插件不会手工移动文件到媒体库；入库始终交给 MoviePilot 的整理链路。
- 删除下载器任务时使用保留文件模式，避免误删已经生成并整理的 MKV。
- 源原盘删除只应发生在 MKV 成功生成、整理入库并完成验证之后。
- 大体积 ISO/BDMV 重封装对磁盘空间和 IO 压力较高，建议根据机器性能设置并行数和磁盘余量。
